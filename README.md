# qedb: Expressive and Modular Verifiable Databases (without SNARKs)

Which is a recursive acronym standing for ***q***edb ***e***rror-checks ***d***ata***b***ases.
It is also a shameless pun on it being a ***proof*** system for DBs.


>[!IMPORTANT]
> **Development Status**: The open-source version of qedb is currently under active development and will be available soon. Star the repository to stay updated on our initial release!


## Description

Verifiable Databases (VDBs) enables clients to verify data integrity and query correctness without trusting the database
provider.

***qedb*** is a new construction for verifiable databases that supports a subset of SQL.
The scheme improves the state of the art among constructions that do not rely on general-purpose SNARKs.
